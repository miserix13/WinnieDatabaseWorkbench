Winnie Database Workbench is a Windows-Forms application for working with databases.

- Features:
	- Query Editor
	- Visual Designer for data definition and schema
	- Management / Admin tooling
	- Currently supported databases: SurrealDB, LiteDB, DuckDB, MS SQL Server, PostgreSQL, MySQL/MariaDB, Firebird, MongoDB, Garnet, Redis, Chroma, Qdrant
